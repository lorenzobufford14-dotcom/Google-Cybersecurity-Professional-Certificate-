# Course 2: Play It Safe - Manage Security Risks

**Certification:** Google Cybersecurity Professional Certificate  
**Status:** In Progress  

---

## 📌 Executive Summary

Course 2 focuses on managing organizational security risks, adhering to compliance standards, analyzing system logs, and responding to incidents using established frameworks.

* **Module 1: Security Domains** — Focuses on the CISSP 8 security domains and identifying threats, risks, and vulnerabilities across business operations.
* **Module 2: Security Frameworks & Controls** — Covers industry frameworks (NIST CSF, CIA Triad) and security controls that protect organizational assets.
* **Module 3: Introduction to Cybersecurity Tools** — Explores Security Information and Event Management (SIEM) tools, dashboards, and log data analysis.
* **Module 4: Incident Response Playbooks** — Details the phases of incident response and using playbooks to remediate security events.
